# 📝 Full Stack MERN Blogging & Social Media Application

A modern **Full Stack MERN Blogging & Social Media Application** built using the **MERN Stack**. The platform allows users to create and manage blogs, follow other users, chat in real-time, and interact through a clean, responsive interface.

## 🚀 Live Demo

🔗 https://blogging-app-eqta.onrender.com/

---

## ✨ Features

* 🔐 User Authentication (JWT)
* 👤 User Registration & Login
* 📝 Create, Edit & Delete Blog Posts
* 📖 Read Blogs
* ❤️ Like & Interact with Posts
* 👥 Follow / Unfollow Users
* 💬 Real-Time Chat System
* 🖼️ User Profile Management
* 🔒 Protected Routes
* 📱 Fully Responsive Design
* ⚡ Fast & Optimized Performance

## ⚙️ Installation

### Clone Repository

```command prompt
git clone https://github.com/Aamirkhan121/MERN-Blogging
```

### Install Dependencies

#### Backend

```command prompt
cd backend
npm install
```

#### Frontend

```command prompt
cd myapp
npm install
```

---

## ▶️ Run Project

### Backend

```command prompt
npm run dev
```

### Frontend

```command prompt
npm run dev
```

---

## 🔑 Environment Variables

Create a `.env` file inside the **server** folder.

```env
PORT=5000
MONGO_URI=YOUR_MONGODB_URI
JWT_SECRET=YOUR_SECRET_KEY
CLIENT_URL=http://localhost:5173
```
